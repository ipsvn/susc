# susc

susc is a reimplementation of the *Among Us* networking protocol, written in C.

it implements a client, able to connect to an Among Us game server and control a player. a server implementation is planned, but not high priority.

this project depends on a reimplementation of [Hazel-Networking](https://github.com/willardf/Hazel-Networking) to C, also [written by me](https://git.svn.lol/svn/hazel-c)
